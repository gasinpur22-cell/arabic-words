# Калимат

Сайт для заучивания арабских слов: по 3 слова в день, интервальные повторы и недельный зачёт.

- `words.js` — словарь, сюда добавляются новые слова.
- `firebase-config.js` — настройки Firebase для общей таблицы (вход только по имени).
- `app.js`, `style.css`, `index.html` — сам сайт.
- `manifest.webmanifest`, `sw.js`, `icons/` — установка на телефон и работа без интернета.
- `fonts/` — шрифты Golos Text, Unbounded и Scheherazade New (лицензия SIL OFL), чтобы не ждать Google Fonts.
- `DESIGN.md` — правила оформления: цвета, шрифты, кнопки.

**После любого изменения файлов сайта подними `VERSION` в `sw.js`**, иначе телефоны продолжат открывать старую версию из офлайн-кеша. Новые слова в `words.js` подхватываются и без этого.

## Как поставить на телефон

- iPhone: открыть сайт в Safari → «Поделиться» → «На экран „Домой“».
- Android: открыть сайт в Chrome → меню ⋮ → «Добавить на главный экран» (или «Установить приложение»).

После первого открытия сайт работает без интернета: страница, шрифты и все фото сохраняются на телефон. Новая версия подтягивается при следующем запуске.

## Правила Firestore

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{id} {
      allow read, write: if true;
    }
  }
}
```
